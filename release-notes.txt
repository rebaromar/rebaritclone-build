وەشانی 19.5
• مۆڵەتی `READ_SMS` و خوێندنەوەی ڕاستەوخۆی نامەکان لابرا.
• گواستنەوەی SMS تەنها بە هەڵبژاردنی فایلێکی پاشەکەوتی پێشتر دروستکراو لە system file picker دەکرێت؛ ئەپەکە نامەی مۆبایل ناخوێنێتەوە.
• SMS لە لیستی گواستنەوەی USBی ڕاستەوخۆ لابرا؛ فایلە هەڵبژێردراوەکان هەر بە نهێنیکراوی دەگوازرێنەوە.
• Play Protect و مۆڵەتەکانی تر ناگۆڕدرێن.

وەشانی 19.4
• چاکسازیی بڵاوکردنەوە: APK ـەکە ئێستا وەک release ـی نادیباگ دروست دەکرێت، نەک build ـی debug.
• واژۆی هەمان کلیل بەکاردێت بۆ ئەوەی دامەزراندنی 19.3 بتوانێت نوێکاری وەربگرێت.
• ئامادەکردنی ئەپە هەڵبژێردراوەکان ئێستا تەنها زانیارییەکانی پاکێج دەخوێنێتەوە؛ APKکان تا کاتی ناردن کۆپی ناکرێن بۆ cache. بۆ 15.8 GB، ئەمە پێش ناردن ئەو کۆپییە گەورەیە لادەبات.
• کۆنتەینەری APK بێ ZIP و بە شێوەی stream نێردرێت؛ کاری فشاردان/کردنەوە و کۆپیکردنی پێشوەختە کەم دەبێتەوە.
• پشتڕاستکردنەوەی SHA-256، نهێنیکردنی پەیوەندی و بەردەوامبوون لە دوای پچڕان پارێزراون. فۆرماتی ZIPی کۆنیش هێشتا وەردەگیرێت.
• بۆ گواستنەوەی ئەپ، هەردوو مۆبایل دەبێت وەشانی 19.3 یان نوێتر هەبێت.
• ئەم چاکسازییانە خێرایی تۆڕ بەڵێن نادەن؛ خێرایی پێویستی بە تاقیکردنەوەی دوو مۆبایلی ڕاستەقینە هەیە.
