وەشانی 19.16
• لە گواستنەوەی USBدا CPU لە خەوتن دەپارێزرێت و thread ـی گواستنەوە بە priority ـی کەمێک بەرزتر کار دەکات؛ دوای گواستنەوە دۆخی سەرەتایی دەگەڕێتەوە.
• قەبارەی USB لە 256 KB دەمێنێتەوە کە لە مۆبایلەکاندا باشتر کار کردووە.

وەشانی 19.15
• دوگمەکانی USB بە «مۆبایلی تازە — وەرگر» و «مۆبایلی کۆن — نێرەر» ڕوونتر کران.
• ناونیشانی picker ـی ئەپ بە ڕوونی دەڵێت هەڵبژاردن لە مۆبایلی تازە ئەنجام بدە؛ لیستەکە بۆ ئەپەکانی مۆبایلی کۆنە.

وەشانی 19.14
• قەبارەی داواکاری و buffer ـی USB گەڕێندرایەوە بۆ 256 KB، چونکە تاقیکردنەوەی بەکارهێنەر لە قەبارەی 1 MB خێرایی کەمتر پیشان دا.

وەشانی 19.13
• QR ـی دابەزاندنی ناو ئەپ و لینکەکانی share/update ڕاستەوخۆ دەچنە `apk.rebarit.store/apk`، بۆ ئەوەی APK ـی نوێ لە لینکە کۆنەکانی MediaFire یان `rebarit.store/app` نەکرێتەوە.

وەشانی 19.12
• لە مۆبایلی کۆن ڕەزامەندیی گواستنەوە لە سەرەتای سێشن وەردەگیرێت؛ دوای هەڵبژاردنی داتا لە مۆبایلی نوێ، ناردن بە خۆکار دەست پێدەکات.
• کاتێک USB دووبارە پەیوەست دەبێتەوە، لە مۆبایلی وەرگرەوە هەڵبژاردنی بەردەوامبوون لە شوێنی پچڕان یان دەستپێکردنەوە لە سەرەتا پیشان دەدرێت.
• دەستپێکردنەوە، فایل و بەشە نیمچەوەستاوەکانی هەمان گواستنەوە پاک دەکات و ناردن لە سەرەتاوە دەست پێدەکات.
• هەردوو مۆبایل دەبێت بۆ ئەم ڕەفتارە نوێیە وەشانی 19.12یان تێدا بێت. داوای ڕێگەپێدانی سیستەمی Android لە کاتی پێویستدا هێشتا لە Androidەوە دەردەکەوێت.

وەشانی 19.11
• چاکسازیی پەیوەندیی USB: ڕێگەپێدانی Android لە کاتی دووبارە پەیوەستبوونی AOAدا بە هەڵە پشتگوێ ناخرێت، کە دووبارە دەرکەوتنی پەنجەرەی ڕێگەپێدان کەم دەکات.
• دوای شکستی پەیوەندی، ئەپەکە بە خۆکارانە داوای ڕێگەپێدانی نوێ ناکات؛ وەرگر چاوەڕێی هەڵبژاردنی بەکارهێنەر دەبێت.
• لە ڕێڕەوی USBدا پەیامی دۆخی گواستنەوە ڕوونترە؛ ئەپە هەڵبژێردراوەکان پێشوەختە کۆپی ناکرێن و ڕاستەوخۆ بۆ stream ئامادە دەکرێن.

وەشانی 19.10
• لە USBدا لیستی ئەپەکانی مۆبایلی کۆن بە پەیوەندیی پارێزراو بۆ مۆبایلی نوێ دەنێردرێت؛ هەڵبژاردن و گەڕان لە مۆبایلی نوێ ئەنجام دەدرێت.
• پەکێجە هەڵبژێردراوەکان لەلایەن مۆبایلی کۆنەوە پشتڕاست دەکرێنەوە، و هەڵبژاردن لە کاتی بەردەوامبوون لە گواستنەوە دەپارێزرێت.
• بۆ ئەم گۆڕانکارییە، هەردوو مۆبایل پێویستە وەشانی 19.10 دامەزرێت.

وەشانی 19.9
• لە گواستنەوەی USBدا هەڵبژاردنی داتا بە شاشەیەکی ڕوونتر، پیشاندانی ژمارە و قەبارە، و هەڵبژاردنی هەموو/هیچ ئاسانکرا.
• پێش ناردنی ئەپەکان، لیستی گەڕانپێکراوی ئەپە دامەزراوەکان دەردەکەوێت؛ دەتوانیت هەر ئەپێک تاک بە تاک هەڵبژێریت.
• قەبارەی buffer و داواکاریی USB bulk بۆ مۆبایلە نوێکان بەرزکراوەتەوە بۆ کەمکردنەوەی سەردانی I/O. خێرایی کۆتایی بە کێبڵ و پشتگیری هەردوو مۆبایلەوە پەیوەستە.

وەشانی 19.8
• ڕەوتی هەڵبژاردنی داتا، چاوەڕوانی وەرگر و ناردن بە هەنگاوی یەکسان و ڕوون پیشان دەدرێت.
• شاشەی چاوەڕوانی وەرگر ئێستا دۆخی پەیوەندی، هەنگاوی چاوەڕوانی و ڕێنمایی ڕوون پیشان دەدات.

وەشانی 19.7
• بلۆکی ناردنی فایل بۆ USB کرا بە 1 MB و قەبارەی داواکاری bulk بەرزکراوەتەوە بۆ کەمکردنەوەی سەردانی I/O و خێراترکردنی گواستنەوە.
• هەڵە نائاساییەکانی کاری ناردن لە worker ـدا تۆمار و پیشان دەدرێن، نەک ئەوەی ئەپ بێ پەیام دابخرێت؛ هەڵەکانی سیستەمی ڕەخنەیی هێشتا بە ڕێزی خۆیان مامەڵەیان لەگەڵ دەکرێت.

وەشانی 19.6
• کۆدی QR ـی پەیوەندی بە پشکنینی H و قەبارەی گەورەتر دروست دەکرێت بۆ خوێندنەوەی ئاسانتر لە مۆبایلە جۆراوجۆرەکان.
• سکانکەر سەرەتا ناوەڕاستی وێنە پشکنین دەکات و ئەگەر پێویست بێت هەموو فریمەکە؛ قەبارەی فریمی کامێراش کەم کراوەتەوە بۆ وەڵامدانەوەی خێراتر.
• گەڕانی Wi‑Fi Direct زووتر دووبارە دەبێتەوە بۆ دۆزینەوەی خێراتری مۆبایلی تر.

وەشانی 19.5
• مۆڵەتی `READ_SMS` و خوێندنەوەی ڕاستەوخۆی نامەکان لابرا.
• گواستنەوەی SMS تەنها بە هەڵبژاردنی فایلێکی پاشەکەوتی پێشتر دروستکراو لە system file picker دەکرێت؛ ئەپەکە نامەی مۆبایل ناخوێنێتەوە.
• SMS لە لیستی گواستنەوەی USBی ڕاستەوخۆ لابرا؛ فایلە هەڵبژێردراوەکان هەر بە نهێنیکراوی دەگوازرێنەوە.
• Play Protect و مۆڵەتەکانی تر ناگۆڕدرێن.

وەشانی 19.4
• چاکسازیی بڵاوکردنەوە: APK ـەکە ئێستا وەک release ـی نادیباگ دروست دەکرێت، نەک build ـی debug.
• واژۆی هەمان کلیل بەکاردێت بۆ ئەوەی دامەزراندنی 19.3 بتوانێت نوێکاری وەربگرێت.
• ئامادەکردنی ئەپە هەڵبژێردراوەکان ئێستا تەنها زانیارییەکانی پاکێج دەخوێنێتەوە؛ APKکان تا کاتی ناردن کۆپی ناکرێن بۆ cache. بۆ 15.8 GB، ئەمە پێش ناردن ئەو کۆپییە گەورەیە لادەبات.
• کۆنتەینەری APK بێ ZIP و بە شێوەی stream نێردرێت؛ کاری فشاردان/کردنەوە و کۆپیکردنی پێشوەختە کەم دەبێتەوە.
• پشتڕاستکردنەوەی SHA-256، نهێنیکردنی پەیوەندی و بەردەوامبوون لە دوای پچڕان پارێزراون. فۆرماتی ZIPی کۆنیش هێشتا وەردەگیرێت.
• بۆ گواستنەوەی ئەپ، هەردوو مۆبایل دەبێت وەشانی 19.3 یان نوێتر هەبێت.
• ئەم چاکسازییانە خێرایی تۆڕ بەڵێن نادەن؛ خێرایی پێویستی بە تاقیکردنەوەی دوو مۆبایلی ڕاستەقینە هەیە.
